01. Comparison

What this script compares

The baseline is this platform at its rated rates, not a general benchmark score.

PartBaseline for this buildHow it is checked
CPUIntel 12th-17th gen at its base clock, boost allowedAll-core load for about five seconds, frequency sampled from % Processor Performance. Socket, vendor, power-plan CPU cap and memory integrity come from Windows.
MemoryDDR4-3200 or DDR5-6000, two channels, 16 GB or moreConfigured speed per stick, channel labels, total capacity, module part numbers. Target for this build: DDR4-3200 / DDR5-6000.
GraphicsAMD Radeon card at full width, power limit at the card default, PCIe 5.0 x16 on Z-series, Gen4 on most B/H boardsPCIe width and generation from Windows, driver date, display mode. Clocks and power limits need Adrenalin; Windows does not expose them.
Motherboard600 / 700 / 800-series chipsetBoard and BIOS identity, socket mismatch, chipset family, BIOS age. Intel microcode updates change power behaviour and stability. Compare the date with the vendor page.
Power supplyAbout 150 W CPU, 300 W GPU, so 750 W and upNot readable in software. The script estimates peak draw and the 12 V current it implies, then leaves the label check to you.
StorageNVMe near 5,000 MB/s (Gen4) or 9,000 MB/s (Gen5), SATA SSD near 500 MB/s192 MB sequential write, then an uncached read on the system drive. Drive health, free space and TRIM are read from Windows.

02. Result

How to read the output

Each line is one measured value against the baseline above.

  • PASSAt or above the baseline.
  • WARNWorking, but below what the platform should hold.
  • FAILClearly outside the baseline, or the wrong part for this script.
  • SKIPWindows did not expose it, or it needs administrator rights or a vendor tool.

The summary names the first failure, or the first warning if nothing failed, and lists up to three. Order is CPU, memory, graphics, board, power, storage, thermals. If everything passes, that line says so and there is nothing further to chase.

03. Limits

What it cannot tell you

  • PSU model and wattage. No Windows API exposes it. The script prints the draw it expects and the 12 V current, and you compare that with the label.
  • Temperatures on AMD and Intel GPUs. There is no command-line sensor source. No command-line sensor source. Clocks, power limits and temperature are left to Adrenalin.
  • Other drives. Every disk is listed, but only the system drive is benchmarked.
  • Random I/O. The disk test is sequential. Boot time and game loads depend more on random reads.
  • Laptop power limits. Battery, vendor profiles and MUX switches change the numbers; the script reads whatever Windows reports at that moment.
  • Overclocks and undervolts. It reports what the machine is set to, not whether that setting is stable.
